# VanillaPlus M1

Pacote de shaders para Minecraft Java, com iluminação quente, sombras suaves, nuvens procedurais, efeitos subaquáticos e um céu próprio para o End. O nome **VanillaPlus M1** aparece na biblioteca compartilhada do projeto.
